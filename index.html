How Realtime Sync Operates:
  1. Web dashboard saves schedules directly to Firebase: /users/{uid}/medicines
  2. ESP32 firmware fetches active reminder schedules via Firebase REST or listens to alarms.
  3. ESP32 local web server provides emergency buzzer test & status checks via HTTP endpoints.

Firebase Database Rules Required

By default, Firebase creates new databases in Locked Mode (.read: false, .write: false). To allow your medicines to save directly to the cloud, paste these rules into your Firebase Console:
  1. Open Firebase Console > Realtime Database > Rules
  2. Replace all existing text with the JSON below and click Publish:
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    }
  }
}
